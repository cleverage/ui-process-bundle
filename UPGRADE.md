Upgrade Guide
=============

## v3.3

### Route names

The routes of the bundle are prefixed with `cleverage_ui_process_`. The former names are deprecated aliases, removed in
4.0: update the references in your application (`path()` / `url()`, `redirectToRoute()`, security configuration when
`security.configure_firewall` is `false`...).

| Before (deprecated)       | After                                  |
|---------------------------|----------------------------------------|
| `process`                 | `cleverage_ui_process` (dashboard)     |
| `process_<crud>_<action>` | `cleverage_ui_process_<crud>_<action>` |
| `process_login`           | `cleverage_ui_process_login`           |
| `process_logout`          | `cleverage_ui_process_logout`          |
| `process_list`            | `cleverage_ui_process_list`            |
| `process_launch`          | `cleverage_ui_process_launch`          |
| `http_process_execute`    | `cleverage_ui_process_http_execute`    |

The routes of the CRUD pages are generated by EasyAdmin from the dashboard route name, e.g.
`process_process_execution_index` is now `cleverage_ui_process_process_execution_index`.

### Upload directory parameter

The `upload_directory` container parameter is deprecated, use `cleverage_ui_process.upload_directory`: it will be
removed in 4.0. Setting `upload_directory` in your application still works (with a deprecation), unless
`cleverage_ui_process.upload_directory` is also set.

```yaml
# config/services.yaml
parameters:
    # Before (deprecated)
    upload_directory: '%kernel.project_dir%/var/imports'
    # After
    cleverage_ui_process.upload_directory: '%kernel.project_dir%/var/imports'
```

### Twig functions and filter

The Twig functions and filter of the bundle are prefixed with `cleverage_ui_process_`. The former names are deprecated,
removed in 4.0: update your templates (e.g. overridden templates of the bundle).

| Before (deprecated)              | After                                                 |
|----------------------------------|-------------------------------------------------------|
| `log_label()`                    | `cleverage_ui_process_log_label()`                    |
| `log_translation()`              | `cleverage_ui_process_log_translation()`              |
| `log_css_class()`                | `cleverage_ui_process_log_css_class()`                |
| `get_last_execution_date()`      | `cleverage_ui_process_get_last_execution_date()`      |
| `get_process_source()`           | `cleverage_ui_process_get_process_source()`           |
| `get_process_target()`           | `cleverage_ui_process_get_process_target()`           |
| `resolve_ui_options()`           | `cleverage_ui_process_resolve_ui_options()`           |
| `md5` (filter)                   | `cleverage_ui_process_md5` (filter)                   |

## v3.0

### Import routes

```yaml
// Before (2.x)
ui-process-bundle:
  resource: '@CleverAgeUiProcessBundle/src/Controller'
  type: attribute

// After (3.x)
ui-process-bundle:
  resource: '@CleverAgeUiProcessBundle/config/routes/*.yaml'
```
